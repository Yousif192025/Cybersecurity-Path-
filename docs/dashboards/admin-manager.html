⚙️ إدارة المقررات والمجموعات الأكاديمية

تحديث جماعي (نظام التصفية الأكاديمي الذكي):

ℹ️ كيف يعمل النظام؟ سيقوم النظام بفحص مسار كل طالب تلقائياً. إذا كان المقرر "مشتركاً" سيشمل الجميع، وإذا كان "تخصصياً" (مثل الفيزياء للحاسب أو التشفير للأمن) سيقوم بتحديث الطلاب المعنيين فقط واستثناء البقية.
