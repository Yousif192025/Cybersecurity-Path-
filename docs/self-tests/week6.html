اليوم الأول — أساسيات Zenmap

التعرف على برنامج Zenmap وتنفيذ أول عمليات فحص الشبكات بشكل عملي ومبسط للمبتدئين.

🎯 أهداف المعمل

  • التعرف على برنامج Zenmap
  • معرفة عنوان IP الخاص بالجهاز
  • تنفيذ فحص بسيط للشبكة
  • فهم المنافذ المفتوحة
  • قراءة نتائج الفحص بشكل مبدئي

📘 ما هو Zenmap ؟

Zenmap هو الواجهة الرسومية الخاصة بأداة Nmap ويستخدم في:

  • اكتشاف الأجهزة داخل الشبكة
  • معرفة المنافذ المفتوحة
  • تحليل الخدمات الموجودة
  • تعلم أساسيات الأمن السيبراني
يفضل تشغيل البرنامج داخل شبكة منزلية أو بيئة تدريبية فقط.

🖥️ التجربة الأولى — معرفة عنوان IP

الخطوات

افتح CMD ثم اكتب:

ipconfig

المطلوب

ابحث عن:

IPv4 Address

مثال:

192.168.1.5

🔍 التجربة الثانية — أول عملية فحص

الخطوات

  • افتح Zenmap
  • في خانة Target اكتب:
127.0.0.1
  • اختر Regular Scan
  • اضغط Scan

ماذا ستشاهد؟

  • المنافذ المفتوحة
  • الخدمات
  • حالة الجهاز

🌐 التجربة الثالثة — اكتشاف الأجهزة بالشبكة

نفذ الأمر التالي:

nmap -sn 192.168.1.0/24

الهدف

  • معرفة عدد الأجهزة المتصلة
  • اكتشاف عناوين IP
الأمر -sn يستخدم لاكتشاف الأجهزة فقط بدون فحص المنافذ.

📡 التجربة الرابعة — فحص جهاز محدد

nmap 192.168.1.1

المطلوب من الطالب

  • تسجيل عدد المنافذ المفتوحة
  • كتابة أرقام المنافذ
  • معرفة أسماء الخدمات

📚 أشهر المنافذ

المنفذ الخدمة
80 HTTP
443 HTTPS
22 SSH
445 SMB

🧪 التجربة الخامسة — فحص الجهاز المحلي

nmap localhost

الهدف

معرفة الخدمات التي تعمل على نفس الجهاز.

📖 حالات المنافذ

الحالة المعنى
open المنفذ مفتوح
closed المنفذ مغلق
filtered المنفذ محمي أو مخفي

📝 الواجب العملي

المطلوب الأول

ipconfig

اكتب:

  • IPv4 Address
  • Default Gateway

المطلوب الثاني

nmap localhost

أجب عن التالي:

  • كم عدد المنافذ المفتوحة؟
  • ما أرقام المنافذ؟
  • ما الخدمات الموجودة؟

المطلوب الثالث

nmap -sn 192.168.1.0/24
  • كم عدد الأجهزة المكتشفة؟
  • اكتب عنواني IP لجهازين على الأقل
