ما هو Zenmap ؟

Zenmap هو الواجهة الرسومية لأداة Nmap (Network Mapper). تساعدك على استكشاف الشبكات، اكتشاف الأجهزة والخدمات، وتعلم أساسيات الأمن الهجومي والدفاعي بطريقة مرئية سهلة.

نصيحة أمنية: استخدم Zenmap فقط على الشبكات التي تملك الإذن بفحصها، مثل شبكتك المنزلية أو بيئة مختبرية.

🧪 معمل Zenmap التفاعلي (محاكي حي)

جرب أوامر المسح بشكل تفاعلي! اضغط على الأزرار لترى نتائج محاكاة احترافية تشبه بيئة Nmap الحقيقية.

⚡ مرحباً بك في محاكي Zenmap — اضغط على أي زر لعرض ناتج الفحص التخيلي.

التجربة الأولى — معرفة الـ IP (ipconfig)

افتح CMD أو Terminal واكتب:

ipconfig # لنظام Windows
ifconfig # لنظام Linux/Mac

المطلوب: ابحث عن IPv4 Address و Default Gateway وسجلهم في نموذج الواجب أدناه.

مثال: IPv4: 192.168.1.100 | Gateway: 192.168.1.1

التجربة الثانية — فحص الجهاز المحلي (nmap localhost)

nmap 127.0.0.1
# أو nmap localhost

يقوم هذا الأمر بفحص المنافذ المفتوحة على جهازك الحالي، ستلاحظ منافذ مثل 135/tcp، 445/tcp، 5040/tcp حسب الخدمات.

التجربة الثالثة — اكتشاف الأجهزة بالشبكة

nmap -sn 192.168.1.0/24

الأمر -sn يكتشف الأجهزة الحية عبر Ping sweep بدون فحص المنافذ. يظهر لك عدد الأجهزة المتصلة في شبكتك المحلية.
