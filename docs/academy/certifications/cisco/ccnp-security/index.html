ما هي شهادة Cisco CCNP Security؟

شهادة Cisco CCNP Security هي شهادة متقدمة في أمن الشبكات، تغطي تصميم وتنفيذ حلول أمنية متكاملة باستخدام تقنيات Cisco. تعتبر خطوة متقدمة بعد CCNA، وتركز على المهارات العملية في تأمين البنية التحتية للشبكات.

ما الذي تثبته الشهادة؟

  • تصميم وتنفيذ حلول أمن الشبكات
  • تكوين جدران الحماية المتقدمة
  • إدارة أنظمة كشف ومنع التسلل
  • تنفيذ تقنيات VPN المتقدمة
  • فهم أمن السحابة والبنية التحتية
معلومات سريعة
  • الجهة المانحة: Cisco
  • المستوى: متقدم
  • رمز الاختبار: 350-701 SCOR
  • المدة المقدرة: 120 دقيقة
  • عدد الأسئلة: 90-100 سؤالاً
  • المتطلبات السابقة: CCNA أو خبرة معادلة
  • التجديد: كل 3 سنوات
  • طريقة الاختبار: مراكز معتمدة أو عبر الإنترنت
