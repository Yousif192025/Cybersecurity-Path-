النماذج الإرشادية (للطباعة والاستخدام المحلي)

ثمانية نماذج بدون حساب وبدون قاعدة بيانات. عبّئ أو اطبع؛ وللاحتفاظ بالإجابات استخدم الطباعة أو «حفظ كـ PDF» من المتصفح.

  1. 1. استبيان الاحتياجات الأولية

    تحديد الاحتياج والخطوة التالية.

  2. 2. التقييم الذاتي للاستعداد والمستوى

    تقييم غير رسمي من 12 درجة.

  3. 3. خطة التعلم الشخصية القصيرة

    هدف وثلاث خطوات قابلة للتنفيذ.

  4. 4. سجل التقدم الأسبوعي

    متابعة أسبوعية ذاتية.

  5. 5. تحليل الصعوبات التعليمية

    وصف الصعوبة قبل طلب الدعم.

  6. 6. قالب الاستعداد لشهادة مهنية

    تنظيم الاستعداد مع الرجوع للمصادر الرسمية.

  7. 7. استكشاف المسار المهني

    ربط الاهتمامات بالمهارات والوظائف.

  8. 8. إعداد طلب المساعدة وتقييم الخدمة

    تجهيز الملخص؛ الإرسال عبر واتساب الوحدة.

هذه قوالب إرشادية وليست نماذج رسمية للجهة التدريبية (حرمان، حذف وإضافة، تظلمات…).
