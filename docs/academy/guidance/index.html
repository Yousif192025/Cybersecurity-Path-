حدود وحدة الإرشاد

  • لا تحل محل المدرّس أو الجهة التعليمية الرسمية في القرارات الأكاديمية أو اعتماد النتائج.
  • لا تضمن اجتياز اختبار أو الحصول على شهادة أو وظيفة.
  • لا تقدم تشخيصًا نفسيًا أو طبيًا، ولا تستبدل المختصين عند الحاجة.
  • النسخة الحالية توجيهية عبر روابط؛ المتابعة البشرية أو حفظ الخطط في حساب تتطلب اعتمادًا لاحقًا.
