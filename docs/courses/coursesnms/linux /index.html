مرحباً بك في مقرر أوامر لينكس الأساسية

يستعرض هذا المقرر قائمةً بأهم أوامر لينكس الشائعة، بحيث يمكنك استخدامها مرجعًا لك لاحقًا. المحتوى مناسبٌ لكلٍ من المستخدم العادي وصاحب الخبرة، مع تركيز على الشرح الواضح والأمثلة التطبيقية.

تم تقسيم المقرر إلى وحدات تعليمية تغطي مختلف جوانب نظام لينكس، بدءاً من الأوامر الأساسية وصولاً إلى أوامر إدارة الحزم والضغط.

وحدات المقرر التعليمي

الوحدة 1: الأوامر الأساسية

أهم الأوامر التي يحتاجها كل مستخدم لينكس للتعامل مع النظام

  • hostnamectl - عرض معلومات النظام
  • date - عرض التاريخ والوقت
  • ls - عرض الملفات والمجلدات
  • cd - التنقل بين المجلدات
  • وغيرها من الأوامر الأساسية
الانتقال إلى الوحدة

الوحدة 2: أوامر إدارة الشبكة

الأوامر المتعلقة بإعدادات وإدارة الشبكات في لينكس

  • ip addr show - عرض عناوين IP
  • netstat - عرض المنافذ النشطة
  • ping - اختبار الاتصال
  • whois - معلومات النطاق
  • وأوامر أخرى متقدمة
الانتقال إلى الوحدة

الوحدة 3: أوامر أذونات الملفات

إدارة صلاحيات الوصول إلى الملفات والمجلدات

  • chmod - تغيير أذونات الملفات
  • chown - تغيير ملكية الملفات
  • ls -l - عرض الأذونات
  • والعديد من الأمثلة التطبيقية
الانتقال إلى الوحدة

الوحدة 4: إدارة المستخدمين والمجموعات

إنشاء وإدارة حسابات المستخدمين والمجموعات

  • useradd - إضافة مستخدم جديد
  • usermod - تعديل بيانات المستخدم
  • groupadd - إنشاء مجموعة جديدة
  • id - عرض معلومات الهوية
الانتقال إلى الوحدة

الوحدة 5: أوامر إدارة العمليات

مراقبة وإدارة العمليات النشطة في النظام

  • ps - عرض العمليات النشطة
  • top - عرض العمليات في الوقت الحقيقي
  • kill - إنهاء العمليات
  • pstree - عرض شجرة العمليات
الانتقال إلى الوحدة

الوحدة 6: أوامر إدارة الأقراص

إدارة مساحة التخزين والأقراص في النظام

  • df - عرض مساحة التخزين
  • mount - توصيل الأجهزة والمجلدات
  • fdisk - إدارة أقسام القرص
  • lsblk - عرض معلومات الكتل

الوحدة 7: أوامر إدارة الحزم

تثبيت وإدارة البرامج والحزم في لينكس

  • apt-get - إدارة الحزم في ديبيان
  • yum - إدارة الحزم في RPM
  • dpkg - إدارة حزم ديبيان
  • التحديث والترقية

الوحدة 8: أوامر الضغط وفك الضغط

ضغط الملفات وفك ضغطها باستخدام أدوات سطر الأوامر

  • tar - أرشيف الملفات
  • zip - ضغط الملفات
  • unzip - فك ضغط الملفات
  • أمثلة عملية متنوعة
