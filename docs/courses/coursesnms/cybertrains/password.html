برمجة سكريبت الأرقام المتسلسلة Shell Script

تعلم خطوة بخطوة كيفية إنشاء سكريبت يطبع أرقامًا متتالية من أي رقم تبدأ إليه، مع شرح تفصيلي للمبتدئين.

تنويه مهم جداً

هذا الفيديو والمحتوى المقدم يهدف إلى نشر المعرفة التقنية الصحيحة حول برمجة السكريبتات وأساسيات الأمن السيبراني. جميع المعلومات مقدمة للأغراض التعليمية فقط. لا نتحمل أي مسؤولية عن أي استخدام غير أخلاقي أو غير قانوني لهذه المعلومات. الهدف هو تمكين المبرمجين والمهتمين من فهم كيفية عمل الأدوات والبرامج بطريقة صحيحة وآمنة.

ملخص الحلقة التعليمية

في هذه الحلقة نشرح بالتفصيل طريقة برمجة سكريبت (Script) بلغة Shell Script يقوم بطباعة أرقام متتالية تبدأ من أي رقم تحدده وتستمر إلى عدد لا نهائي (حتى إيقافه). سنشرح الكود سطراً سطراً ونتعرف على أساسيات البرمجة بلغة Bash، وكيف يمكن للمبتدئين بناء أدواتهم الخاصة.

ماذا ستتعلم؟

  • ✓ كتابة سكريبت بلغة Bash من الصفر
  • ✓ استخدام الحلقات (loops) والتعبيرات الشرطية
  • ✓ التعامل مع المدخلات والمخرجات
  • ✓ تنفيذ السكريبت من الهاتف (باستخدام Termux)

المتطلبات

  • • أي نظام لينكس / أو محاكي (Termux للاندرويد)
  • • محرر نصوص (nano, vim, أو أي محرر)
  • • حماس للتعلم!

جرب السكريبت بنفسك (محاكاة تفاعلية)

أدخل رقم البداية، وسيقوم السكريبت الافتراضي بطباعة الأرقام المتتالية في المربع أدناه (محاكاة تعليمية).

📜 كود السكريبت (شرح تفصيلي)

#!/bin/bash
# سكريبت طباعة أرقام متتالية - للأغراض التعليمية

echo "أدخل رقم البداية:"
read start

echo "أدخل رقم النهاية (أو اترك فارغاً لطباعة لا نهائية):"
read end

counter=$start

if [ -z "$end" ]; then
    # إذا لم يدخل المستخدم نهاية، نطبع إلى ما لا نهاية (يوقف بـ Ctrl+C)
    while true; do
        echo "الرقم: $counter"
        counter=$((counter + 1))
        sleep 0.5   # تأخير اختياري للعرض
    done
else
    # طباعة من البداية إلى النهاية
    while [ $counter -le $end ]; do
        echo "الرقم: $counter"
        counter=$((counter + 1))
    done
fi

الشرح: السطر الأول #!/bin/bash يحدد أن السكريبت سيتم تنفيذه باستخدام Bash. نطلب من المستخدم إدخال رقم البداية والنهاية (اختياري). إذا لم يتم إدخال نهاية، يستمر السكريبت في طباعة الأرقام إلى ما لا نهاية (حتى نوقفه بـ Ctrl+C). وإلا يطبع من البداية إلى النهاية. المتغير $counter يحتفظ بالرقم الحالي، ويتم زيادته في كل دورة.

استخدامات عملية وأخلاقية

هذا السكريبت هو مثال بسيط يوضح آلية عمل الحلقات والتكرار. يمكن توظيف هذه المعرفة في:

  • أتمتة المهام المتكررة (مثل إعادة تسمية ملفات).
  • إنشاء أدوات مساعدة للمطورين.
  • فهم كيفية عمل أدوات اختبار الاختراق (لكن يجب استخدامها فقط في بيئاتك الخاصة أو بإذن).

تذكير أخلاقي:

لا تستخدم هذه المعرفة لاختراق أي نظام أو حساب دون إذن. الاختراق غير القانوني جريمة يعاقب عليها القانون. الهدف هو فهم التقنيات للدفاع وحماية الأنظمة.

تشغيل السكريبت من الهاتف (Termux)

يمكنك تجربة السكريبت على هاتفك الأندرويد باستخدام تطبيق Termux بسهولة:

  1. حمّل تطبيق Termux من F-Droid أو متجر خارجي.
  2. افتح التطبيق واكتب: pkg install bash
  3. أنشئ ملفاً جديداً: nano counter.sh
  4. الصق الكود أعلاه، ثم احفظ (Ctrl+X ثم Y ثم Enter).
  5. شغّل السكريبت: bash counter.sh
