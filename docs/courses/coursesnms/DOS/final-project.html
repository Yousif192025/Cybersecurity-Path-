أساسيات أوامر Windows CMD للأمن السيبراني — المشروع الختامي

تقييم خط الأساس الأمني لنظام Windows

Windows Security Baseline Assessment — WIN-LAB-01

المقدمة

هذا المشروع هو التطبيق الختامي للمقرر. ستوظف فيه كل ما تعلمته في الوحدات العشر — بدءًا من أوامر CMD الأساسية، وصولًا إلى تحليل السجلات، جدار الحماية، المهام المجدولة، والأتمتة بـ Batch وPowerShell.

بيئة المشروع افتراضية بالكامل: جهاز مختبري باسم WIN-LAB-01، ببيانات ثابتة معدّة مسبقًا. لن تفحص جهازك، ولن تنفذ أوامر حقيقية، ولن تعدّل أي إعداد.

🛡️
هذه بيئة مختبرية افتراضية. جميع البيانات والنتائج محاكاة تعليمية وليست مستخرجة من جهاز حقيقي.

أهداف المشروع

بنهاية المشروع ستكون قادرًا على:

  1. تحليل معلومات نظام Windows الافتراضية.
  2. تفسير صلاحيات الملفات والمجلدات.
  3. تقييم حسابات المستخدمين والمجموعات والامتيازات.
  4. قراءة بيانات الشبكة والتمييز بين IP وMAC.
  5. تحليل العمليات والخدمات وربطها بالسياق.
  6. تفسير أحداث سجلات Windows وربطها زمنيًا.
  7. تقييم إعدادات جدار الحماية وملفات التعريف.
  8. تحليل المهام المجدولة ومؤشرات الاستمرارية.
  9. فهم دور Batch وPowerShell في الأتمتة.
  10. اكتشاف مؤشرات التهيئة غير المناسبة أو السلوك المشبوه.
  11. إعداد تقرير أمني منظم يتضمن النتائج والتوصيات.

سيناريو المشروع

أنت محلل أمني في فريق الدعم التقني. طُلب منك إعداد تقييم أمني أولي لمحطة عمل افتراضية تعمل بنظام Windows. تم تزويدك ببيانات ثابتة عن الجهاز المختبر WIN-LAB-01.

مهمتك:

  1. مراجعة البيانات في المراحل التسع.
  2. تدوين الملاحظات الأمنية في سجل الملاحظات.
  3. تصنيف كل ملاحظة حسب الخطورة.
  4. إعداد تقرير أمني نهائي قابل للطباعة.
⚠️
جميع البيانات والأسماء والتواريخ في هذا المشروع خيالية وثابتة. لا توجد أي بيانات شخصية حقيقية.

المطلوب: ما أهمية كل معلومة في التقييم الأمني؟

اعرض التوجيه
Host Name يميّز الجهاز في الشبكة. OS Name/Version يحدد إن كان النظام مدعومًا ويحتاج تحديثات. System Type يؤثر على توافق الأدوات. Current User يحدد السياق الأمني. Uptime القصير قد يشير إلى إعادة تشغيل حديثة (تحديث أو حادث) ويستحق المراجعة.

الأوامر المناسبة: ipconfig /all, arp -a.

المطلوب: ما دلالة العناوين والبوابة وDNS؟

اعرض التوجيه
IPv4 عنوان منطقي داخل الشبكة المحلية، وMAC عنوان فيزيائي. Default Gateway يوجّه الحزم خارج الشبكة المحلية. DNS Servers يحوّل الأسماء إلى عناوين. ARP يربط IP بـ MAC. إدخال DNS عام (8.8.8.8) ضمن شبكة داخلية قد يستحق المراجعة (اعتماد خارجي)، لكنه ليس مؤشرًا قاطعًا.

7تقييم جدار الحماية

البيانات الافتراضية:

ProfileStatusInboundOutboundLogBlocked
DomainONBlockAllowTrue
PrivateONBlockAllowTrue
PublicOFFAllowAllowFalse

الأوامر المناسبة: netsh advfirewall show allprofiles.

المطلوب: ما الإعدادات التي تستحق المراجعة؟

اعرض التوجيه
Public OFF مؤشر خطر مرتفع — يجعل الجهاز مكشوفًا في الشبكات العامة. Public Inbound: Allow سياسة مفتوحة تزيد سطح الهجوم. LogBlocked: False يفقدك القدرة على التحليل الجنائي. الإجراء المقترح: تفعيل Public مع سياسة Block Inbound (في بيئة إنتاج، وليس هنا).
8تحليل المهام المجدولة

المهام الافتراضية:

Task NamePathRun AsActionSchedule
ScheduledDefrag\Microsoft\Windows\DefragSYSTEM%windir%\system32\defrag.exeWeekly
WindowsUpdateHelper\CustomTasksSYSTEMC:\Users\Public\wuhelper.exeDaily
LogRotator\MaintenanceSYSTEMC:\Program Files\LogTools\rotate.exeEvery 5 min

الأوامر المناسبة: schtasks /query /v /fo LIST.

المطلوب: ما المهام التي تستحق المراجعة؟

اعرض التوجيه
ScheduledDefrag مهمة نظامية معروفة، لا مؤشر شذوذ (مع بقاء التحقق من التوقيع). WindowsUpdateHelper اسم يشبه مهمة نظامية لكنه في مجلد مخصص ويشغّل ملفًا من مجلد المستخدم العام — مؤشرات قوية. LogRotator مسار معتاد، لكن جدولة كل 5 دقائق أداة تدوير سجلات غير معتادة. لا يمكن الجزم بالخبث من البيانات وحدها.
9تحليل الأتمتة وPowerShell

مقطع Batch افتراضي:

@echo off
set STATUS=READY
if "%STATUS%"=="READY" echo Proceed
for %%I in (alpha beta gamma) do echo Item: %%I

مقطع PowerShell افتراضي:

Get-Process | Where-Object { $_.ProcessName -eq "notepad" } | Select-Object ProcessName, Id

المطلوب: ما وظيفة كل مقطع؟ وهل يوجد خطأ منطقي؟

اعرض التوجيه
Batch: يعرّف متغيرًا، يفحص شرطًا، ثم يكرر على ثلاثة عناصر ويطبعها. لا يوجد خطأ منطقي في هذا المقطع — الشرط صحيح، والحلقة صحيحة. PowerShell: يجلب العمليات، يصفّيها لعرض notepad فقط، ثم يختار العمودين ProcessName وId. لا يوجد خطأ. ملاحظة سلامة: لا تشغّل أي سكربت مجهول المصدر، حتى لو بدا بسيطًا.

سجل الملاحظات والتقييم

أضف ملاحظاتك الأمنية المستندة إلى البيانات الافتراضية. كل ملاحظة تحتاج: الوصف، الدليل، مستوى الخطورة، التفسير، والتوصية.

لم تُضف أي ملاحظات بعد.

التقرير النهائي

يُبنى التقرير تلقائيًا من الملاحظات المسجلة. راجع الملاحظات قبل الطباعة.

مخرجات الطالب المطلوبة

  • ملخص تنفيذي واضح (150-250 كلمة).
  • تحليل مكتوب للأقسام التسعة مستندًا إلى البيانات الافتراضية.
  • خمس ملاحظات أمنية على الأقل مسجلة في سجل الملاحظات.
  • تصنيف كل ملاحظة حسب الخطورة مع تبرير.
  • خمس توصيات عملية على الأقل.
  • خلاصة توضح حدود التقييم (ما يمكن وما لا يمكن إثباته).
  • التمييز بين السلوك الطبيعي والمؤشر الذي يحتاج إلى تحقق.
