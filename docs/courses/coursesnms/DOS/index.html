أساسيات أوامر Windows CMD للأمن السيبراني

Windows CMD Fundamentals for Cybersecurity

مقرر تدريبي متكامل يأخذك من الصفر إلى إتقان سطر أوامر Windows من منظور دفاعي وأمني: جمع المعلومات، تحليل الشبكات، إدارة الصلاحيات، قراءة السجلات، واكتشاف الأنشطة المشبوهة.

ابدأ الوحدة الأولى جرّب الاختبار النهائي

مقدمة تعريفية

سطر أوامر Windows (CMD) أداة قوية لإدارة النظام والتحقيق الأمني. في هذا المقرر ستتعلم استخدامه بشكل منهجي وآمن، مع التركيز على الفهم الدفاعي: كيف تستخدم الأوامر لجمع الأدلة، تحليل الحالة الأمنية، واكتشاف سلوك المهاجمين.

الوصف العام

عشر وحدات تعليمية مستقلة، كل وحدة تحتوي شرحًا نظريًا، أمثلة عملية، تمارين، تحديات، واختبارًا قصيرًا. وينتهي المقرر بمشروع عملي واختبار نهائي تفاعلي.

الأهداف التعليمية

  • إتقان أوامر CMD الأساسية والمتقدمة.
  • جمع معلومات النظام والشبكة بشكل منهجي.
  • تحليل المستخدمين والصلاحيات والخدمات.
  • قراءة سجلات Windows وتفسير الأحداث الأمنية.
  • فهم أساليب المهاجمين لأغراض الكشف والدفاع.
  • التمهيد للانتقال إلى PowerShell والأتمتة.

المخرجات التعليمية

  • تشغيل أوامر CMD بأمان وتفسير نتائجها.
  • إعداد تقرير تقييم أمني أساسي لنظام Windows.
  • تمييز الأوامر الخطرة والاستخدامات الدفاعية.
  • بناء سكربت أتمتة بسيط بـ CMD / PowerShell.

الفئة المستهدفة

المبتدئون في الأمن السيبراني، طلاب تقنية المعلومات، ومحللو الدعم الفني الراغبون في تطوير مهاراتهم الأمنية.

المتطلبات السابقة

معرفة أساسية باستخدام Windows، وفهم عام لمفاهيم الشبكات. لا حاجة لخبرة برمجية مسبقة.

المدة الزمنية المقترحة

20–25 ساعة موزعة على 10 وحدات، بمعدل 2–2.5 ساعة لكل وحدة، إضافة إلى المشروع والاختبار النهائي.
