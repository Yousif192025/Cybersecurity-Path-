إدارة الملفات والمجلدات

مقدمة

في التحقيق الأمني وجمع الأدلة، تتعامل مع ملفات ومجلدات باستمرار: سجلات، ملفات إعدادات، أرشيفات مشبوهة، ملفات تشغيل. إتقان أوامر التنقل والنسخ والبحث يوفر وقتًا كبيرًا ويقلل الأخطاء.

أهداف الوحدة

  • التنقل بين المجلدات وعرض المحتويات.
  • نسخ ونقل وحذف الملفات بأمان.
  • البحث عن الملفات بناءً على معايير.
  • عرض محتوى الملفات النصية وتحليلها.
  • استخدام إعادة التوجيه لحفظ المخرجات كأدلة.

شرح تفصيلي للأوامر

1) dir

الصيغة:

dir [path] [/a] [/s] [/o:order]
  • /a: عرض الملفات المخفية والنظامية.
  • /s: عرض الملفات في المجلدات الفرعية.
  • /o:d: ترتيب حسب التاريخ.

مثال:

dir C:\Windows\System32 /a
dir C:\Users /s /o:d

النتيجة المتوقعة: قائمة الملفات مع الحجم والتاريخ والخصائص.

الاستخدام الأمني: كشف الملفات المخفية والملفات المعدّلة حديثًا.

2) cd

الصيغة:

cd [path]
cd ..
cd \

cd .. للصعود مستوى، cd \ للجذر.

3) mkdir / rmdir

الصيغة:

mkdir folderName
rmdir folderName
rmdir /s /q folderName
تحذير: rmdir /s /q يحذف المجلد بكل محتوياته دون تأكيد. لا تستخدمه إلا في بيئة اختبار.

4) copy

الصيغة:

copy source destination
copy file.txt D:\backup\

ملاحظة: لا ينسخ المجلدات. لنسخ مجلد استخدم xcopy أو robocopy.

5) move

الصيغة:

move source destination
move log.txt C:\Evidence\

6) del

الصيغة:

del file.txt
del /s *.tmp
تحذير: del لا ينقل إلى سلة المحذوفات. لا يمكن التراجع بسهولة.

7) xcopy و robocopy

الصيغة:

robocopy source dest /E /COPYALL

النتيجة: نسخ كامل مع السماحات والطوابع الزمنية — مفيد لحفظ الأدلة.

8) type

الصيغة:

type file.txt

الاستخدام الأمني: قراءة ملفات الإعدادات والسجلات بسرعة.

9) findstr

الصيغة:

findstr /i /s "password" C:\Logs\*.log

البحث عن نص داخل ملفات متعددة. مفيد للبحث عن مؤشرات اختراق (IoC).

10) إعادة التوجيه (>, >>)

الصيغة:

dir > output.txt
systeminfo >> audit.txt

الاستخدام الأمني: حفظ مخرجات الأدوات كأدلة بوقت محدد.

الاستخدامات الأمنية

  • جمع الأدلة عبر نسخ احتياطي بنظام robocopy.
  • البحث عن كلمات مفتاحية مشبوهة باستخدام findstr.
  • حفظ مخرجات الفحص في ملف نصي للتوثيق.

الأخطاء الشائعة

  • استخدام del أو rmdir /s /q على مسار حساس دون نية.
  • نسيان نسخ السماحات عند الأدلة (استخدم robocopy /COPYALL).
  • عدم إضافة /a عند البحث عن ملفات مخفية.

تمارين عملية

  1. اعرض محتويات مجلد المستخدم مع الملفات المخفية.
  2. أنشئ مجلدًا باسم Evidence داخل D:\.
  3. انسخ ملفًا وثبّت حفظ الطوابع الزمنية باستخدام robocopy.
  4. ابحث عن كلمة "error" داخل ملفات .log.

تحديات تطبيقية

  • أنشئ سكربتًا يحفظ مخرجات dir C:\ /a في ملف D:\audit_dir.txt.
  • ابحث في C:\Users عن ملفات .exe معدّلة في آخر 7 أيام (استخدم forfiles).

اختبار قصير

ملخص

تعلمنا التنقل، النسخ، النقل، البحث، وتوثيق المخرجات. هذه مهارات ستُستخدم في كل وحدة قادمة.
