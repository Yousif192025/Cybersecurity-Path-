إدارة الملفات والمجلدات

مقدمة

في التحقيق الأمني وجمع الأدلة، تتعامل مع ملفات ومجلدات باستمرار: سجلات، إعدادات، أرشيفات مشبوهة، ملفات تشغيل. إتقان أوامر التنقل والنسخ والبحث يوفر وقتًا كبيرًا ويقلل الأخطاء.

في هذه الوحدة لن تتعلم أوامر متفرقة، بل ستبني مختبرًا تدريبيًا متكاملًا داخل مجلد المستخدم، وتبني عليه خطوة بخطوة.

أهداف الوحدة

  • التنقل بين المجلدات وعرض المحتويات.
  • إنشاء ملفات ومجلدات داخل مختبر آمن.
  • نسخ ونقل الملفات وفهم الفروق بين copy و xcopy و robocopy.
  • البحث داخل الملفات باستخدام findstr.
  • عرض خصائص الملفات باستخدام attrib.
  • عرض هيكل المجلدات باستخدام tree.
  • حفظ المخرجات في ملفات باستخدام > و >>.
  • فهم مخاطر أوامر الحذف والاستخدام الآمن لها.

إعداد المختبر الآمن

كل تطبيقات هذه الوحدة ستُجرى داخل مجلد المختبر: %USERPROFILE%\Desktop\CyberPath-Lab. لا نستخدم مجلدات النظام ولا أقراصًا غير مضمونة.

خطوات إعداد المختبر

  1. افتح CMD (عاديًا يكفي في هذه الوحدة).
  2. انتقل إلى سطح المكتب:
cmd
cd %USERPROFILE%\Desktop
  1. أنشئ مجلد المختبر:
cmd
mkdir CyberPath-Lab
  1. ادخل المختبر:
cmd
cd CyberPath-Lab
من الآن فصاعدًا، كل الأوامر تُنفَّذ داخل CyberPath-Lab. أي أمر حذف ستستخدمه لاحقًا سيستهدف ملفات داخل المختبر فقط.

1) معرفة المسار الحالي — cd

الهدف: التأكد أنك داخل مجلد المختبر قبل أي عملية.

متى نستخدمه؟ قبل كل خطوة لتفادي العمليات في مسار خاطئ.

المتطلبات: لا يحتاج صلاحيات.

cmd
cd

المخرجات المتوقعة (نموذج):

output
C:\Users\Yousif\Desktop\CyberPath-Lab

التفسير: أنت الآن داخل المختبر، وهذا المسار هو نقطة البداية.

الاستخدام الأمني: التحقق من مسار التنفيذ قبل حفظ الأدلة أو حذف الملفات.

خطأ شائع: كتابة مسار غير موجود يعطي "The system cannot find the path specified".

تمرين: نفّذ cd وسجّل الناتج.

سؤال تطبيقي: ماذا يحدث لو نفّذت cd .. الآن؟

2) استعراض الملفات — dir

الهدف: عرض محتويات المجلد الحالي أو مجلد محدد.

متى نستخدمه؟ لمعرفة ما بداخل المختبر قبل وبعد كل عملية.

المتطلبات: لا يحتاج صلاحيات.

الصيغة

cmd
dir [path] [/a] [/s] [/o:order]

شرح الخيارات:

  • /a: عرض كل الملفات بما فيها المخفية والنظامية.
  • /s: عرض الملفات داخل المجلدات الفرعية.
  • /o:d: ترتيب حسب التاريخ.

خطوات التنفيذ

  1. تأكد أنك داخل المختبر بـ cd.
  2. نفّذ الأمر التالي:
cmd
dir /a

المخرجات المتوقعة (نموذج):

output
 Volume in drive C has no label.
 Volume Serial Number is 1234-ABCD

 Directory of C:\Users\Yousif\Desktop\CyberPath-Lab

11/07/2026  10:12 AM    <DIR>          .
11/07/2026  10:12 AM    <DIR>          ..
               0 File(s)              0 bytes
               2 Dir(s)  45,678,901,234 bytes free

تفسير المخرجات: في البداية المجلد فارغ، ويظهر فقط . (المجلد الحالي) و .. (المجلد الأب).

الاستخدام الأمني: كشف الملفات المخفية والملفات المعدّلة حديثًا للاشتباه.

خطأ شائع: نسيان /a فيظهر المجلد فارغًا رغم وجود ملفات مخفية.

تمرين: نفّذ dir /a ثم dir /a /o:d وقارن الترتيب.

سؤال تطبيقي: أي خيار يعرض الملفات داخل المجلدات الفرعية؟

3) الانتقال بين المجلدات — cd

الهدف: التنقل بين المجلدات للعمل في المكان الصحيح.

متى نستخدمه؟ للدخول إلى مجلد فرعي أو الرجوع للخلف.

الصيغة

cmd
cd [path]
cd ..
cd \

خطوات التنفيذ

  1. أنشئ مجلدًا فرعيًا:
cmd
mkdir subfolder
  1. ادخل إليه:
cmd
cd subfolder
  1. ارجع للخلف:
cmd
cd ..

المخرجات المتوقعة: لا تظهر أي رسالة عند النجاح، ويتغير المسار في موجه الأوامر.

التفسير: cd .. يصعد مستوى واحدًا، cd \ ينتقل لجذر القرص الحالي.

الاستخدام الأمني: التنقل داخل مجلدات الأدلة بحذر دون الخروج إلى مسارات النظام.

خطأ شائع: نسيان المسافة بين cd و ...

تمرين: ادخل subfolder ثم اخرج بـ cd ...

سؤال تطبيقي: ما الفرق بين cd .. و cd \؟

4) إنشاء مجلد — mkdir

الهدف: إنشاء مجلد جديد لتنظيم الملفات.

متى نستخدمه؟ لبناء هيكل مختبر أو حفظ الأدلة.

cmd
mkdir logs

المخرجات المتوقعة: لا تظهر رسالة عند النجاح.

التفسير: يُنشأ مجلد logs داخل المختبر.

الاستخدام الأمني: إنشاء مجلدات لتنظيم الأدلة بحسب النوع أو التاريخ.

خطأ شائع: إنشاء مجلد باسم يحتوي مسافات دون علامات تنصيص.

تمرين: أنشئ مجلدًا باسم evidence.

سؤال تطبيقي: ما الأمر الذي يحذف مجلدًا فارغًا؟

5) إنشاء ملف نصي — echo مع إعادة التوجيه

الهدف: إنشاء ملف نصي يحتوي على محتوى محدد.

متى نستخدمه؟ لتوثيق ملاحظات أو إنشاء ملف اختبار للبحث.

الصيغة

cmd
echo [text] > filename.txt

خطوات التنفيذ

  1. أنشئ ملفًا يحتوي على نص:
cmd
echo Login success for user admin > event.txt
  1. أضف سطرًا آخر إلى نفس الملف (إضافة لا استبدال):
cmd
echo Login failed for user guest >> event.txt
  1. اعرض محتوى الملف:
cmd
type event.txt

المخرجات المتوقعة:

output
Login success for user admin
Login failed for user guest

التفسير: > يستبدل محتوى الملف، و >> يضيف إليه.

الاستخدام الأمني: بناء ملفات اختبار للبحث، أو توثيق نتائج التحقيق.

خطأ شائع: استخدام > بدلًا من >> فيفقد المحتوى السابق.

تمرين: أنشئ ملف notes.txt يحتوي على سطرين.

سؤال تطبيقي: ما الفرق بين > و >>؟

6) قراءة ملف نصي — type

الهدف: عرض محتوى ملف نصي داخل النافذة.

متى نستخدمه؟ لقراءة سجلات أو ملفات إعدادات بسرعة.

cmd
type event.txt

المخرجات المتوقعة: نفس محتوى الملف كما أنشأته.

التفسير: type يعرض النص فقط، ولا يعدّل الملف.

الاستخدام الأمني: قراءة سجلات التطبيقات النصية أو ملفات إعدادات مريبة.

خطأ شائع: محاولة عرض ملفات غير نصية فيظهر رموز غير مفهومة.

تمرين: اعرض notes.txt.

سؤال تطبيقي: ما الأمر البديل لعرض ملف طويل بصفحات؟ (تلميح: more)

7) نسخ ملف — copy

الهدف: إنشاء نسخة من ملف دون حذف الأصل.

متى نستخدمه؟ قبل أي تعديل على ملف مهم، أو لحفظ نسخة احتياطية.

cmd
copy event.txt event_backup.txt

المخرجات المتوقعة:

output
        1 file(s) copied.

التفسير: تم إنشاء نسخة باسم event_backup.txt داخل المختبر.

الاستخدام الأمني: أخذ نسخة من ملف قبل تحليله أو تعديله.

خطأ شائع: استخدام copy لنسخ مجلد كامل — لا ينسخ المجلدات.

تمرين: انسخ event.txt إلى logs\event_copy.txt.

سؤال تطبيقي: أي أمر ينسخ مجلدًا كاملًا بكل محتوياته؟

8) نقل ملف — move

الهدف: نقل ملف من مكان إلى آخر (حذف من الأصل).

متى نستخدمه؟ لتنظيم الملفات في مجلدات الأدلة.

cmd
move event_backup.txt logs\

المخرجات المتوقعة:

output
        1 file(s) moved.

التفسير: الملف انتقل إلى logs ولم يبقَ في المختبر الرئيسي.

الاستخدام الأمني: تنظيم الأدلة داخل مجلدات مخصصة.

خطأ شائع: نسيان \ بعد اسم المجلد، فيُفهم كاسم ملف.

تمرين: انقل event_backup.txt من logs إلى subfolder.

سؤال تطبيقي: ما الفرق بين copy و move؟

9) البحث داخل الملفات — findstr

الهدف: البحث عن نص معين داخل ملف أو عدة ملفات.

متى نستخدمه؟ للبحث عن مؤشرات اختراق (IoC) أو كلمات مشبوهة.

الصيغة

cmd
findstr [/i] [/s] "pattern" [files]

شرح الخيارات:

  • /i: تجاهل حالة الأحرف.
  • /s: البحث في المجلدات الفرعية.

خطوات التنفيذ

  1. ابحث عن كلمة failed في event.txt:
cmd
findstr /i "failed" event.txt
  1. ابحث في كل الملفات النصية داخل المجلد:
cmd
findstr /i /s "failed" *.txt

المخرجات المتوقعة: السطر الذي يحتوي على الكلمة فقط.

التفسير: إذا لم تظهر مخرجات، فالكلمة غير موجودة.

الاستخدام الأمني: البحث عن كلمات مثل "password" أو "admin" في ملفات الإعدادات.

خطأ شائع: نسيان /i فيضيع جزء من النتائج.

تمرين: ابحث عن كلمة admin في جميع ملفات .txt.

سؤال تطبيقي: ما الفرق بين findstr و type؟

10) خصائص الملفات — attrib

الهدف: عرض أو تعديل خصائص الملف (مخفي، للقراءة فقط، نظامي).

متى نستخدمه؟ لكشف الملفات المخفية أو تعديل خصائص ملف.

cmd
attrib event.txt

المخرجات المتوقعة (نموذج):

output
A    C:\Users\Yousif\Desktop\CyberPath-Lab\event.txt

التفسير: A يعني أن الملف أرشيفي. الرموز الأخرى: H مخفي، S نظامي، R للقراءة فقط.

الاستخدام الأمني: كشف ملفات مخفية أو نظامية قد يضعها المهاجم.

خطأ شائع: تعديل خصائص ملفات النظام دون سبب.

تمرين: أضف خاصية "مخفي" إلى event.txt:

cmd
attrib +h event.txt

سؤال تطبيقي: كيف تُزيل خاصية "مخفي"؟

11) عرض هيكل المجلدات — tree

الهدف: عرض شجرة المجلدات بشكل مرئي.

متى نستخدمه؟ لفهم هيكل مجلد كبير بسرعة.

cmd
tree /f

المخرجات المتوقعة (نموذج):

output
C:.
├───logs
│       event_backup.txt
├───subfolder
└───event.txt

التفسير: /f يعرض الملفات مع المجلدات. بدون /f يعرض المجلدات فقط.

الاستخدام الأمني: رسم هيكل مجلدات مشبوهة في التحقيق.

خطأ شائع: الاعتقاد أن tree يعرض الملفات المخفية — استخدم dir /a لذلك.

تمرين: نفّذ tree ثم tree /f.

سؤال تطبيقي: ما الفرق بين tree و tree /f؟

12) الفرق بين copy و xcopy و robocopy

الأمرالملفاتالمجلداتالسماحاتالاستخدام
copyنعملالانسخ ملف بسيط
xcopy /Eنعمنعمجزئيًانسخ مجلد
robocopy /Eنعمنعمنعم (مع /COPYALL)نسخ احتياطي للأدلة

مثال robocopy لحفظ الأدلة:

cmd
robocopy logs logs_backup /E /COPYALL

المخرجات المتوقعة: ملخص بعدد الملفات المنسوخة.

التفسير: /COPYALL ينسخ الملف مع المالك والسماحات ومعلومات التدقيق، وليس الطوابع الزمنية فقط.

الاستخدام الأمني: الحفاظ على أدلة سليمة للمحاكمة الجنائية الرقمية.

خطأ شائع: استخدام /COPYALL دون صلاحيات كافية لعرض مالك الملف.

تمرين: انسخ مجلد logs إلى logs_backup باستخدام robocopy.

سؤال تطبيقي: أي أمر ينسخ المالك والسماحات مع الملفات؟

13) حفظ نتائج الأوامر — > و >>

الهدف: حفظ مخرجات أي أمر في ملف.

متى نستخدمه؟ لتوثيق نتائج الفحص كأدلة.

cmd
dir /a > audit_dir.txt
cmd
tree /f >> audit_dir.txt

المخرجات المتوقعة: لا يظهر شيء في الشاشة لأن المخرجات ذهبت إلى الملف.

التفسير: الملف audit_dir.txt يحتوي على مخرجات الأمرين متتاليين.

الاستخدام الأمني: أرشيف أدلة موثّق لكل خطوة.

خطأ شائع: استخدام > عدة مرات فيُستبدل الملف كل مرة.

تمرين: احفظ مخرجات attrib في ملف attrib_log.txt.

سؤال تطبيقي: كيف تحفظ مخرجات أمرين في نفس الملف؟

14) الحذف ومخاطره — del و rmdir

الهدف: حذف ملفات أو مجلدات داخل المختبر فقط.

متى نستخدمه؟ لتنظيف المختبر بعد التمارين.

الصيغة

cmd
del [file]
rmdir [folder]
rmdir /s /q [folder]

خطوات التنفيذ الآمنة

  1. تأكد أنك داخل المختبر بـ cd.
  2. اعرض الملفات قبل الحذف بـ dir.
  3. احذف ملفًا محددًا داخل المختبر:
cmd
del event.txt
تحذير مهم: del و rmdir /s /q لا ينقلان إلى سلة المحذوفات، ولا يمكن التراجع بسهولة. لا تستخدمهما إلا داخل CyberPath-Lab. لا توجّه أي أمر حذف إلى C:\Windows أو أي مسار نظام.

المخرجات المتوقعة: لا رسالة عند الحذف.

التفسير: الملف اختفى من dir.

الاستخدام الأمني: تنظيف المختبر بعد التحقيق، وعدم المساس بالأدلة الأصلية.

خطأ شائع: استخدام rmdir /s /q في مسار خاطئ.

تمرين: احذف event_backup.txt داخل logs، ثم احذف مجلد subfolder بعد التأكد أنه فارغ.

سؤال تطبيقي: ما الفرق بين rmdir و rmdir /s /q؟

الأخطاء الشائعة في الوحدة

  • استخدام مسارات نظام في أمثلة الحذف أو التعديل.
  • نسيان أن copy لا ينسخ المجلدات.
  • الاعتقاد أن /COPYALL ينسخ الطوابع الزمنية فقط.
  • استخدام > بدلًا من >> فيفقد المحتوى السابق.
  • تعديل خصائص ملفات نظام عبر attrib دون سبب.

تمارين عملية متسلسلة

  1. أنشئ مجلد المختبر وتأكد من المسار.
  2. أنشئ مجلد logs و subfolder.
  3. أنشئ ملف event.txt بسطرين.
  4. اعرض الملف بـ type.
  5. انسخه إلى event_backup.txt.
  6. انقل النسخة إلى logs.
  7. ابحث عن كلمة failed داخل الملفات.
  8. أضف خاصية "مخفي" إلى event.txt ثم اعرضها.
  9. اعرض شجرة المجلدات.
  10. احفظ مخرجات tree /f في audit_dir.txt.
  11. احذف النسخة الاحتياطية داخل logs ثم احذف المجلد.

تحديات تطبيقية

  • أنشئ سكربتًا يحفظ مخرجات dir /a و tree /f في ملف واحد داخل المختبر.
  • ابحث في المختبر عن كل الملفات التي تحتوي كلمة admin، واحفظ النتائج في search_result.txt.
  • أنشئ نسخة احتياطية من logs باستخدام robocopy و/COPYALL، وتحقق من حفظ السماحات.
  • استخدم attrib لإخفاء ملف ثم عرضه في dir /a.

اختبار قصير

ملخص

بنيت مختبرًا آمنًا داخل %USERPROFILE%\Desktop\CyberPath-Lab، وتدرّبت على التنقل، الإنشاء، القراءة، النسخ، النقل، البحث، خصائص الملفات، عرض الشجرة، حفظ المخرجات، والحذف الآمن.

مراجع موثوقة

  • Microsoft Learn — dir, copy, robocopy, findstr, attrib.
  • Windows IT Pro Center — File and Folder Management.
