أساسيات أوامر Windows CMD للأمن السيبراني — الوحدة الأخيرة

الوحدة العاشرة: الأتمتة الأساسية والانتقال إلى PowerShell

Basic Automation & Introduction to PowerShell

المقدمة

في الوحدات التسع السابقة تعلمت أوامر CMD واحدة تلو الأخرى. في هذه الوحدة الأخيرة ننتقل من تنفيذ الأمر الواحد إلى بناء سكربتات قابلة للتكرار، ونمهّد الطريق للانتقال إلى PowerShell كأداة أتمتة أقوى وأكثر مرونة.

هدف هذه الوحدة ليس تحويلك إلى مطور سكربتات محترف، بل تعليمك:

  • كيف تُجمَّع الأوامر في ملف Batch وتُشغَّل بأمان.
  • كيف تُدار الشروط والحلقات في CMD.
  • كيف يُستخدم PowerShell للأتمتة والتحليل.
  • كيف تميّز بين سكربت مشروع وسكربت مجهول المصدر.
💡
جميع الأمثلة والمخرجات في هذه الوحدة افتراضية لأغراض التدريب. المحاكي لا ينفذ أوامر حقيقية ولا يقرأ جهازك.

أهداف التعلم

بنهاية هذه الوحدة ستكون قادرًا على:

  1. فهم مفهوم أتمتة المهام في Windows وفوائدها الأمنية والإدارية.
  2. التمييز بين تنفيذ الأمر يدويًا وتجميعه في ملف Batch.
  3. كتابة سكربت Batch بسيط باستخدام: @echo off, echo, set, if, for, pause, exit /b.
  4. فهم ترتيب شروط if errorlevel وأهميته.
  5. استخدام for %%A in (...) وfor /f للمعالجة التكرارية.
  6. فهم الفرق الجوهري بين CMD (نصوص) وPowerShell (كائنات).
  7. استخدام أوامر PowerShell الأساسية: Get-Command, Get-Date, Get-Process, Where-Object, Select-Object, Measure-Object.
  8. فهم Pipeline ونقل الكائنات عبر |.
  9. التمييز بين أتمتة مشروعة وسكربتات مجهولة المصدر.

المحور الأول: مقدمة إلى الأتمتة

أتمتة المهام تعني تحويل سلسلة من الأوامر المتكررة إلى سكربت ينفذها تلقائيًا. بدلًا من كتابة الأوامر واحدًا تلو الآخر كل يوم، تُكتب مرة واحدة وتُشغَّل متى احتجت.

فوائد الأتمتة

  • توفير الوقت: سكربت واحد بدل عشرات الأوامر اليومية.
  • تقليل الخطأ البشري: السكربت ينفذ نفس الخطوات بدقة.
  • إمكانية المراجعة: يمكن قراءة السكربت وفهم ما سيفعله قبل تشغيله.
  • الأتمتة الأمنية: جمع السجلات، تحليل العمليات، إعداد تقارير دورية.

يدويًا مقابل Batch

يدويًا: تكتب الأمر في CMD، تضغط Enter، تكرر العملية.
في Batch: تجمع الأوامر في ملف .bat، تشغّله مرة واحدة، فينفذ كل الأوامر بالتسلسل.

المحور الثاني: ملفات Batch

ما هو ملف Batch؟

ملف Batch هو ملف نصي بامتداد .bat أو .cmd يحتوي أوامر CMD تُنفذ بالتسلسل عند تشغيل الملف. يُشغَّل من CMD بكتابة اسمه (أو بمسار كامل).

بنية ملف Batch النموذجية

example.bat 
@echo off
rem مثال تعليمي
set LABNAME=CyberPath
if exist "C:\Windows" (
    echo النظام موجود
) else (
    echo تحقق من المسار
)
pause

الأمر @echo off

  • الصيغة: @echo off
  • الوظيفة: يمنع عرض الأوامر نفسها أثناء التنفيذ (يبقي المخرجات فقط).
  • ملاحظة: العلامة @ قبل echo تمنع عرض الأمر نفسه أيضًا.
  • الخطأ الشائع: نسيانه فيظهر كل سطر من السكربت قبل تنفيذه.

الأمر echo

  • الصيغة: echo [النص]
  • الوظيفة: طباعة نص أو متغير على الشاشة.
  • مثال: echo Hello CyberPath → يعرض Hello CyberPath.
  • الخطأ الشائع: وضع علامات اقتباس حول النص عند عدم الحاجة، فتظهر ضمن المخرجات.

الأمر rem

  • الصيغة: rem [نص] أو :: [نص]
  • الوظيفة: تعليق — لا يُنفذ، يُستخدم للتوثيق.
  • مثال: rem هذا سطر تعليقي

الأمر set

  • الصيغة: set VAR=value
  • الوظيفة: تعريف متغير واستخدامه لاحقًا بـ %VAR%.
  • مثال: set LAB=CyberPath ثم echo %LAB% → يعرض CyberPath.
  • الخطأ الشائع: وجود مسافة حول = فيصبح الاسم مختلفًا.

الأمر pause

  • الوظيفة: يوقف التنفيذ حتى يضغط المستخدم أي مفتاح.
  • الفائدة: إتاحة الفرصة لقراءة المخرجات قبل إغلاق النافذة.

الأمر exit /b

  • الوظيفة: الخروج من السكربت (أو من روتين فرعي) دون إغلاق نافذة CMD بالكامل.
  • الاستخدام: exit /b 0 للنجاح، exit /b 1 للفشل.

المتغير %ERRORLEVEL%

  • الوظيفة: يحمل رمز نتيجة آخر أمر نُفذ: 0 = نجاح، غير ذلك = خطأ.
  • الاستخدام: if %ERRORLEVEL% NEQ 0 echo فشل الأمر
⚠️
مهم: ERRORLEVEL يُضبط بواسطة الأمر السابق فقط. أي أمر بينك وبين الأمر المراد فحصه سيعيد ضبطه.

المحور الثالث: الشروط والتحكم في سير التنفيذ

الأمر if

الصيغة الأساسية:

if 
C:\> if condition (
    rem تنفيذ عند تحقق الشرط
) else (
    rem تنفيذ عند عدم تحقق الشرط
)

الأمر if exist

يتحقق من وجود ملف أو مجلد:

if exist 
C:\> if exist "C:\Windows" echo النظام موجود

الأمر if errorlevel

يتحقق من قيمة ERRORLEVEL:

if errorlevel 
C:\> if errorlevel 1 echo فشل الأمر
🚫
تحذير ترتيب مهم: if errorlevel N يتحقق عندما تكون قيمة ERRORLEVEL مساوية أو أكبر من N. لذلك يجب فحص القيم الأعلى أولًا:
if errorlevel 3 ... ثم if errorlevel 2 ... ثم if errorlevel 1 ...
عكس الترتيب سيجعل الشروط الأولى تلتقط كل الحالات.

goto و:label

للانتقال إلى قسم محدد داخل السكربت:

goto / label 
C:\> goto end
rem ... أوامر أخرى ...
:end
echo done

المحور الرابع: الحلقات باستخدام FOR

الصيغة الأساسية

for %%A in (...) do ... 
C:\> for %%A in (alpha beta gamma) do echo Item: %%A

Item: alpha
Item: beta
Item: gamma
⚠️
فرق مهم: في سطر الأوامر التفاعلي تستخدم %A (علامة واحدة). داخل ملف Batch تستخدم %%A (علامتان).

for /f لقراءة أسطر

for /f 
C:\> for /f "tokens=*" %%L in (list.txt) do echo Line: %%L

Line: alpha
Line: beta
Line: gamma

مثال تحليلي: معالجة أسماء ملفات افتراضية

for + معالجة 
C:\> for %%F in (log1.txt log2.txt log3.txt) do echo Processing: %%F

Processing: log1.txt
Processing: log2.txt
Processing: log3.txt

الاستخدام الأمني: تكرار فحص ملفات سجل افتراضية، أو تلخيص بيانات من ملفات متعددة. لا تُستخدم هذه الأمثلة للوصول إلى ملفات حقيقية في هذا التدريب.

المحور الخامس: بناء سكربت Batch تعليمي

سكربت افتراضي يوضح: عنوان تقرير، متغيرات، شرط، حلقة FOR، وملخص.

report.bat 
@echo off
set LAB=CyberPath
set STATUS=READY
echo === Security Report ===
echo Lab: %LAB%
echo Status: %STATUS%
if "%STATUS%"=="READY" (
    echo Analysis can proceed.
) else (
    echo Analysis blocked.
)
echo --- Processing items ---
for %%I in (alpha beta gamma) do echo Item: %%I
echo --- End of report ---
pause

المخرجات المتوقعة

output نص عادي 
=== Security Report ===
Lab: CyberPath
Status: READY
Analysis can proceed.
--- Processing items ---
Item: alpha
Item: beta
Item: gamma
--- End of report ---
Press any key to continue . . .

شرح سطر بسطر

  • @echo off — إخفاء عرض الأوامر نفسها.
  • set LAB=CyberPath — تعريف متغير باسم المختبر.
  • set STATUS=READY — تعريف حالة افتراضية.
  • سطور echo — طباعة بيانات التقرير.
  • if "%STATUS%"=="READY" — فحص الحالة واتخاذ قرار.
  • for %%I in (alpha beta gamma) — تكرار على عناصر افتراضية.
  • pause — إيقاف مؤقت لقراءة المخرجات.

المحور السادس: مقدمة إلى PowerShell

ما هو PowerShell؟

PowerShell هو إطار أتمتة وإدارة تكوين من Microsoft، يعتمد على سطر أوامر ولغة سكربت معًا. يختلف عن CMD في أنه يتعامل مع كائنات (Objects) بدلًا من مجرد نصوص.

الفرق بين CMD وPowerShell

الجانبCMDPowerShell
وحدة البياناتنصوص (Strings)كائنات (Objects)
المخرجاتنص عاديكائنات قابلة للتصفية والاختيار
الأوامرأوامر CMDCmdlets بأسلوب Verb-Noun
الأتمتةBatch بسيطسكربتات متقدمة
التعامل مع البياناتمحدودمرن جدًا

مفهوم Cmdlets ونمط Verb-Noun

كل أمر في PowerShell يُسمى Cmdlet ويتبع نمط Verb-Noun (فعل - اسم)، مثل:

  • Get-Process — Get (فعل) + Process (اسم).
  • Get-Service — Get (فعل) + Service (اسم).
  • Select-Object — Select (فعل) + Object (اسم).

هذا النمط يجعل الأوامر متوقعة وقابلة للاكتشاف.

مفهوم Pipeline بـ |

خط الأنابيب (|) يمرر مخرجات أمر إلى أمر آخر. في PowerShell، تُمرَّر الكائنات، مما يتيح للأمر التالي التعامل مع خصائصها مباشرة.

Windows PowerShell 5.1 و PowerShell 7

Windows PowerShell 5.1 مدمج في Windows. PowerShell 7 إصدار أحدث ومتعدد المنصات. في هذا التدريب لا تحتاج إلى تفاصيل الإصدارات — المبادئ والأوامر الأساسية متشابهة.

المحور الثامن: Pipeline في PowerShell

الـ Pipeline يمرر مخرجات أمر إلى أمر آخر باستخدام |. المميز في PowerShell أن الممرَّر هو كائنات، وليس مجرد نصوص.

    180      11   4120   6810 3412  svchost

Select-Object 
PS C:\> Get-Process | Select-Object ProcessName, Id

ProcessName    Id

svchost      3412

المحور التاسع: الأتمتة والتحليل الأمني

يمكن استخدام Batch وPowerShell في:

  • تنظيم التقارير: جمع بيانات دورية إلى ملف واحد.
  • تحليل السجلات: فحص ملفات افتراضية وتلخيصها.
  • تصنيف العمليات والخدمات: عرض العمليات النشطة أو الخدمات المتوقفة.
  • تلخيص نتائج الفحص: استخدام Measure-Object لعدّ النتائج.
  • بناء إجراءات متكررة: سكربتات تُشغَّل أسبوعيًا أو بعد كل فحص.
🚫
تحذير أمني مهم: لا تشغّل ملفات .bat أو .ps1 من مصدر مجهول. قد تحتوي على أوامر خبيثة، أو تعديلات على النظام، أو تسريب بيانات. راجع محتوى السكربت، مصدره، وصلاحياته قبل الاعتماد.

مؤشرات سكربت مشبوه

  • سكربت مشفر أو غامض غير قابل للقراءة.
  • يطلب صلاحيات إدارية دون مبرر واضح.
  • يحاول تعطيل Firewall أو مضاد الفيروسات.
  • يتصل بعناوين شبكية غير معروفة.
  • ينشئ مهامًا مجدولة أو مفاتيح بدء تشغيل.
  • يعمل من مسار مؤقت أو من مجلد المستخدم العام.

المحاكي التفاعلي الآمن

اكتب الأمر بنفسك أو اختر مثالًا جاهزًا. المحاكي يعرض مخرجات افتراضية ثابتة للأوامر المدعومة. لا ينفذ أوامر حقيقية، ولا يقرأ جهازك، ولا يتصل بأي شبكة.

🛡️
تنبيه: هذا محاكي تعليمي يعرض نتائج افتراضية ثابتة، ولا ينفذ أوامر Batch أو PowerShell حقيقية.
محاكي الأتمتة — نتائج افتراضية ثابتة
C:\>
// المحاكي جاهز. اكتب أمرًا في الحقل أعلاه أو اختر مثالًا جاهزًا.
الأوامر المدعومة (Batch): echo · set · if · for · pause · rem
الأوامر المدعومة (PowerShell): Get-Help · Get-Command · Get-Date · Get-Location · Get-ChildItem · Get-Process · Get-Service · Where-Object · Select-Object · Format-Table · Measure-Object

السيناريوهات والتمارين والتحديات

السيناريوهات الثلاثة

1سكربت تقرير دوري

سكربت Batch افتراضي يجمع بيانات ويطبع تقريرًا يوميًا.

@echo off
echo === Daily Report ===
echo Status: OK
pause

سؤال: ما فوائد هذا السكربت الأمنية؟

اعرض التحليل
يوفّر وقتًا، ويضمن تكرار نفس الخطوات بدقة، ويُنتج تقريرًا موحدًا يسهل مراجعته. لكن يجب مراجعة محتوى السكربت مرة واحدة قبل الاعتماد عليه، والتأكد من مصدره.
2سكربت مجهول المصدر

وجدت ملف update.bat في مجلد التنزيلات يطلب صلاحيات إدارية ويُشغّل أوامر غير مقروءة.

سؤال: ما التصرف الصحيح؟

اعرض التحليل
لا تشغّله. سكربت مجهول المصدر يطلب صلاحيات إدارية مؤشر خطر. راجع محتواه أولًا، تحقق من المصدر، واستخدم بيئة معزولة إن أردت الفحص. لا تشغّل أي سكربت دون فهم ما يفعله.
3تقرير PowerShell

أمر PowerShell يجمع العمليات ويحسب عددها:

Get-Process | Measure-Object

سؤال: ما فائدة ذلك في التحليل الأمني؟

اعرض التحليل
عدّ العمليات يساعد في اكتشاف أي زيادة غير طبيعية (مثل هجوم يفتح عمليات كثيرة). يمكن بعدها استخدام Where-Object لتصفية عمليات مشبوهة، وSelect-Object لعرض أعمدة محددة فقط.

التمارين الثمانية

1وظيفة @echo off

ما وظيفة @echo off في بداية ملف Batch؟

اعرض الإجابة
يمنع عرض الأوامر نفسها أثناء التنفيذ، ويُبقي المخرجات فقط.
2الفرق بين %A و%%A

ما الفرق بين %A و%%A في حلقات FOR؟

اعرض الإجابة
%A يُستخدم في سطر الأوامر التفاعلي، و%%A داخل ملف Batch.
3ترتيب if errorlevel

لماذا يجب فحص errorlevel الأعلى أولًا؟

اعرض الإجابة
لأن if errorlevel N يتحقق عندما تكون القيمة مساوية أو أكبر من N. فحص القيم الصغيرة أولًا سيجعل الشرط يلتقط كل الحالات.
4set والمسافات

لماذا يُعد وجود مسافة حول = في set خطأً شائعًا؟

اعرض الإجابة
لأن المتغير سيُعرَّف باسم مختلف (يشمل المسافة)، وقد لا يعمل %VAR% كما تتوقع.
5Get-Command

ما وظيفة Get-Command؟

اعرض الإجابة
يعرض قائمة بالأوامر المتاحة، ويساعد على اكتشاف Cmdlets بأسلوب Verb-Noun.
6Where-Object

ما الفرق بين Select-Object وWhere-Object؟

اعرض الإجابة
Select-Object يختار أعمدة محددة، وWhere-Object يصفّي الكائنات بشرط.
7Pipeline

ماذا يمرر Pipeline في PowerShell؟

اعرض الإجابة
كائنات (Objects) وليس مجرد نصوص. لذلك يمكن للأمر التالي التعامل مع خصائصها مباشرة.
8سلامة السكربتات

ما أهم إجراء قبل تشغيل سكربت Batch أو PowerShell جديد؟

اعرض الإجابة
قراءة محتوى السكربت بالكامل، التحقق من مصدره، والتأكد من الصلاحيات التي يطلبها. لا تشغّل أي سكربت لا تفهم محتواه.

التحديان التطبيقيان

Aتحدي 1: قراءة سكربت
@echo off
set COUNT=3
for /l %%i in (1,1,%COUNT%) do echo Item %%i

سؤال: ماذا يطبع هذا السكربت؟

اعرض الإجابة
يطبع: Item 1، Item 2، Item 3 — لأن الحلقة تبدأ من 1 وتزيد 1 حتى تصل 3.
Bتحدي 2: خطأ في سكربت
@echo off
if errorlevel 1 echo failure
if errorlevel 3 echo severe

سؤال: ما الخطأ المنطقي؟

اعرض الإجابة
ترتيب الشروط معكوس. يجب فحص errorlevel 3 أولًا ثم errorlevel 1، وإلا فإن الشرط الأول (1) سيلتقط كل القيم ≥ 1، والثاني لن يُنفَّذ.

الاختبار القصير

اختبار من 10 أسئلة يغطي مفاهيم وأوامر الوحدة.

ملخص الوحدة

  • أتمتة المهام تحوّل سلسلة أوامر متكررة إلى سكربت قابل للتشغيل.
  • ملف Batch بامتداد .bat أو .cmd يحتوي أوامر CMD تُنفذ بالتسلسل.
  • @echo off يخفي عرض الأوامر، وecho يطبع، وrem يعلّق.
  • set يعرّف متغيرًا يُستخدم بـ %VAR%.
  • if وif exist وif errorlevel للتحكم في سير التنفيذ.
  • ترتيب if errorlevel يجب أن يبدأ بالأعلى.
  • for %%A in (...) يكرر على عناصر، وfor /f يقرأ أسطرًا.
  • PowerShell يعتمد على كائنات Cmdlets بأسلوب Verb-Noun.
  • Pipeline | يمرر كائنات، وليس مجرد نصوص.
  • Where-Object للتصفية، Select-Object للاختيار، Measure-Object للحساب.
  • لا تشغّل سكربتات مجهولة المصدر — راجع محتواها ومصدرها وصلاحياتها.
