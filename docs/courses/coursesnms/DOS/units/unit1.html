مدخل إلى Windows CMD

مقدمة

سطر أوامر Windows (Command Prompt) هو واجهة نصية تتيح لك التحكم الكامل في النظام عبر كتابة الأوامر. في الأمن السيبراني يُستخدم CMD لجمع المعلومات، فحص الحالة الأمنية، التحقيق في الحوادث، وتوثيق الأدلة، لأنه سريع وقابل للتسجيل والأتمتة.

في هذه الوحدة لن تكتفي بقراءة الأوامر، بل ستنفذها بنفسك خطوة بخطوة داخل بيئة آمنة.

أهداف الوحدة

  • فهم طبيعة CMD والفرق بينه وبين PowerShell.
  • فتح CMD بالوضع العادي وبوضع المسؤول.
  • قراءة موجه الأوامر والمسار الحالي.
  • فهم بنية الأمر: الأمر + الخيارات + المعاملات.
  • استخدام نظام المساعدة help و /?.
  • استخدام أوامر أساسية: cls, echo, title, ver, exit.
  • التمييز بين الأوامر الآمنة والأوامر التي تحتاج حذرًا.

1) ما هو CMD؟

CMD (Command Prompt) هو مفسر أوامر نصي في Windows، يعمل عبر الملف cmd.exe الموجود في C:\Windows\System32\. تكتب فيه أمرًا فينفذه النظام ويعرض النتيجة نصيًا.

الميزة الأساسية: قابل للتوثيق والأتمتة. كل ما تفعله يمكن تسجيله وحفظه في ملف، وهذا أساس التحقيق الأمني.

3) كيفية فتح CMD

هذه خطوات تنفيذها على واجهة Windows وليست أوامر CMD:

  1. اضغط Win + R لفتح نافذة التشغيل.
  2. اكتب cmd ثم اضغط Enter.
  3. تظهر نافذة سوداء فيها موجه الأوامر.

طرق بديلة:

  1. اضغط Win + X ثم اختر Terminal أو Windows PowerShell.
  2. من شريط عنوان أي مجلد في المستكشف، اكتب cmd واضغط Enter لفتح CMD في ذلك المسار.

4) الفرق بين التشغيل العادي والتشغيل كمسؤول

بعض الأوامر (تعديل جدار الحماية، إنشاء مستخدم، تعديل الخدمات) تتطلب صلاحيات مرتفعة. عند التشغيل كمسؤول يظهر في عنوان النافذة Administrator.

خطوات فتح CMD كمسؤول:

  1. اضغط Win واكتب cmd.
  2. انقر بزر الفأرة الأيمن على Command Prompt.
  3. اختر Run as administrator.
  4. وافق على نافذة UAC.
تحذير: لا تشغّل CMD كمسؤول إلا عند الحاجة الفعلية، لتقليل الأثر عند تنفيذ أمر خاطئ.

5) التعرف على موجه الأوامر والمسار الحالي

يبدأ كل سطر بمسار مثل C:\Users\Yousif>. ما بعد > هو مكان كتابة الأوامر.

لمعرفة المسار الحالي نستخدم الأمر:

الأمر: cd (عرض المسار الحالي)

الهدف التعليمي: معرفة المجلد الذي تعمل فيه حاليًا.

متى نستخدمه؟ قبل أي عملية ملفات، للتأكد أنك في المكان الصحيح.

المتطلبات: لا يحتاج صلاحيات خاصة.

cmd
cd

مثال عملي: نفّذ الأمر في نافذة CMD جديدة.

المخرجات المتوقعة (نموذج):

output
C:\Users\Yousif

تفسير المخرجات: السطر يعني أنك تعمل داخل مجلد المستخدم Yousif.

الاستخدام الأمني: التحقق من مسار التنفيذ قبل حفظ الأدلة في مكان معروف.

الأخطاء الشائعة: كتابة مسار خاطئ بعد cd يعطي رسالة "The system cannot find the path specified".

تمرين: نفّذ cd ثم اكتب النتيجة التي ظهرت لك.

سؤال تطبيقي: ماذا يعني إن ظهر المسار C:\Windows\System32 بعد تنفيذ cd؟

6) فهم بنية الأوامر

الأمر في CMD يتكون من ثلاثة أجزاء:

  • الأمر: اسم الأداة، مثل dir.
  • الخيارات (Options): تبدأ بـ / مثل /a.
  • المعاملات (Arguments): قيم يمررها الأمر، مثل اسم ملف أو مسار.
cmd
dir C:\Users /a

هنا: dir الأمر، C:\Users معامل، /a خيار.

7) استخدام help

الهدف: عرض قائمة الأوامر أو توثيق أمر محدد.

متى نستخدمه؟ عند نسيان صيغة أمر أو خياراته.

المتطلبات: لا يحتاج صلاحيات.

cmd
help

المخرجات المتوقعة: قائمة بالأوامر الداخلية في CMD.

cmd
help dir

المخرجات المتوقعة: توثيق الأمر dir مع خياراته.

التفسير: اقرأ قسم Syntax لمعرفة الصيغة العامة.

الاستخدام الأمني: تفادي أخطاء الأوامر الخطرة بالرجوع للتوثيق.

خطأ شائع: help لا يعمل مع كل الأدوات الخارجية؛ استخدم /? لتغطية أوسع.

تمرين: اعرض توثيق copy.

سؤال تطبيقي: أي أمر يعرض توثيق net؟

8) استخدام /? للحصول على المساعدة

الهدف: الحصول على المساعدة لأي أمر تقريبًا.

متى نستخدمه؟ عندما لا يوفّر help توثيقًا.

cmd
dir /?

المخرجات المتوقعة: توثيق dir كامل مع الخيارات.

التفسير: نفس توثيق help dir لكن يعمل مع أدوات خارجية أيضًا.

الاستخدام الأمني: قبل تنفيذ أي أمر غير مألوف، اقرأ توثيقه.

خطأ شائع: كتابة ? دون / لا يعمل.

تمرين: اعرض توثيق tasklist.

سؤال تطبيقي: ما الفرق بين help dir و dir /?؟

9) استخدام cls

الهدف: مسح الشاشة لبدء جلسة نظيفة.

متى نستخدمه؟ قبل التقاط مخرجات نظيفة أو بدء فحص جديد.

cmd
cls

المخرجات المتوقعة: شاشة فارغة مع موجه الأوامر أعلى النافذة.

التفسير: لا يحذف شيئًا من النظام، فقط يمسح عرض النافذة.

الاستخدام الأمني: بدء تحقيق بمخرجات نظيفة قابلة للتوثيق.

خطأ شائع: الاعتقاد أن cls يمسح السجلات — لا يفعل.

تمرين: نفّذ help ثم cls.

سؤال تطبيقي: هل يؤثر cls على سجلات Windows؟

10) استخدام echo

الهدف: طباعة نص أو قيمة متغير بيئة.

متى نستخدمه؟ للتوثيق السريع أو لقراءة متغيرات مثل اسم المستخدم.

cmd
echo Hello CyberPath

المخرجات المتوقعة: Hello CyberPath.

cmd
echo %USERNAME%

المخرجات المتوقعة (نموذج): Yousif.

التفسير: %USERNAME% متغير بيئة يعرض اسم المستخدم الحالي.

الاستخدام الأمني: إدراج اسم المستخدم والجهاز في تقرير التحقيق تلقائيًا.

خطأ شائع: نسيان إشارات % حول اسم المتغير فيظهر النص حرفيًا.

تمرين: اطبع قيمة %COMPUTERNAME%.

سؤال تطبيقي: أي متغير يعرض مسار مجلد المستخدم؟

11) استخدام title

الهدف: تغيير عنوان نافذة CMD.

متى نستخدمه؟ عند فتح عدة نوافذ للتمييز بينها أثناء التحقيق.

cmd
title Security Audit Session

المخرجات المتوقعة: يتغير عنوان النافذة إلى النص المكتوب.

التفسير: العنوان أداة تنظيمية، لا يؤثر على النظام.

الاستخدام الأمني: تمييز نوافذ التحقيق بحسب الهدف أو الوقت.

خطأ شائع: عدم استخدام علامات تنصيص عند وجود مسافات معقدة (نادرًا ما يلزم).

تمرين: غيّر العنوان إلى "CyberPath Unit1".

سؤال تطبيقي: لماذا يفيد title أثناء التحقيق؟

12) استخدام ver

الهدف: عرض إصدار Windows.

متى نستخدمه؟ للتحقق السريع من إصدار النظام قبل أي فحص أمني.

cmd
ver

المخرجات المتوقعة (نموذج):

output
Microsoft Windows [Version 10.0.22631.3085]

التفسير: الرقم الأول 10 أو 11 يدل على الإصدار الرئيسي. الأرقام اللاحقة تفاصيل البناء.

الاستخدام الأمني: تسجيل إصدار النظام في تقرير التقييم.

خطأ شائع: توقع تفاصيل أكثر مما يعرضه ver؛ للتفاصيل استخدم systeminfo.

تمرين: نفّذ ver وسجّل الناتج.

سؤال تطبيقي: ما الفرق بين ver و systeminfo؟

13) استخدام exit

الهدف: إغلاق نافذة CMD أو إنهاء سكربت.

cmd
exit

المخرجات المتوقعة: تُغلق النافذة فورًا.

التفسير: في السكربتات، exit /b ينهي السكربت دون إغلاق النافذة.

الاستخدام الأمني: إنهاء جلسة تحقيق بعد حفظ المخرجات.

خطأ شائع: استخدام exit داخل سكربت قبل حفظ المخرجات.

تمرين: احفظ مخرجات ver في ملف ثم نفّذ exit.

سؤال تطبيقي: ما الفرق بين exit و exit /b؟

الأخطاء الشائعة في الوحدة

  • نسيان أن الأمر يحتاج صلاحيات مسؤول.
  • استخدام / بدلًا من \ في مسارات Windows.
  • نسخ أوامر من الإنترنت دون فهمها.
  • الخلط بين خطوات واجهة Windows وأوامر CMD.
لا تنفّذ أوامر خطرة على جهازك الشخصي. استخدم دائمًا جهازًا افتراضيًا (VM).

تمارين عملية

  1. افتح CMD عاديًا ونفّذ whoami.
  2. اعرض توثيق copy باستخدام help و /?.
  3. اطبع %USERNAME% و %COMPUTERNAME% و %DATE%.
  4. غيّر عنوان النافذة إلى "Unit1 Lab".
  5. نفّذ ver وسجّل الناتج في مفكرة.

تحديات تطبيقية

  • اجمع في ملف واحد اسم المستخدم واسم الجهاز وإصدار النظام باستخدام echo وإعادة التوجيه >.
  • افتح نافذتين CMD، ضع عنوانًا مختلفًا لكل منهما.
  • استخدم / ? لاكتشاف خيار يعرض المساعدة للأمر net.
