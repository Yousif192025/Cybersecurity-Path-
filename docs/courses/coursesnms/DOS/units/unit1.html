مدخل إلى Windows CMD

مقدمة

سطر أوامر Windows (Command Prompt أو CMD) هو واجهة نصية تتيح لك التحكم الكامل في النظام عبر كتابة أوامر بدلًا من النقر على الواجهة الرسومية. في مجال الأمن السيبراني، يُعد CMD أداة أساسية لجمع المعلومات، فحص الحالة الأمنية، والتحقيق في الحوادث، لأن معظم الأوامر سريعة، قابلة للتسجيل، ويمكن أتمتتها داخل سكربتات.

أهداف الوحدة

  • فهم طبيعة CMD والفرق بينه وبين PowerShell.
  • فتح CMD بصلاحيات عادية وبصلاحيات مسؤول.
  • فهم بنية الأمر: الأمر + الخيارات + المعاملات.
  • استخدام نظام المساعدة لعرض توثيق أي أمر.
  • التعرف على الأوامر الخطرة وكيفية تجنبها.

شرح نظري

يعمل CMD عبر ملف cmd.exe الموجود في C:\Windows\System32\. عند كتابة أمر، يبحث CMD عنه بالترتيب: أوامر داخلية، ثم مسارات PATH، ثم الامتدادات القابلة للتنفيذ (.exe, .bat, .cmd).

الصلاحيات مهمة جدًا: بعض الأوامر (مثل تعديل جدار الحماية أو إنشاء مستخدم) تتطلب تشغيل CMD كمسؤول (Administrator). يمكنك معرفة ما إذا كنت مسؤولًا عبر الأمر whoami /groups أو ببساطة ملاحظة عنوان النافذة (يظهر "Administrator" في العنوان عند التشغيل المرتفع).

CMD مقابل PowerShell: CMD بسيط وسريع للأوامر المباشرة، أما PowerShell فهو بيئة أتمتة حديثة تعتمد على الكائنات (Objects). سنستخدم CMD هنا كأساس، وسنمهد لـ PowerShell في الوحدة 10.

شرح تفصيلي للأوامر

1) فتح CMD

طرق شائعة:

Win + R → اكتب cmd → Enter
Win + X → Terminal (Admin)  أو  Windows PowerShell (Admin)
اكتب في شريط العنوان لمجلد: cmd  ثم Enter

2) help و /?

الصيغة:

help
help [command]
[command] /?

مثال:

help dir
dir /?

النتيجة المتوقعة: عرض توثيق الأمر مع الخيارات المتاحة.

التفسير: استخدم /? عند نسيان خيارات أي أمر؛ هي أسرع طريقة للتحقق بدلًا من البحث على الإنترنت.

3) cls

الصيغة:

cls

الوظيفة: مسح الشاشة. مفيد قبل التقاط مخرجات نظيفة.

4) echo

الصيغة:

echo [text]
echo %USERNAME%

مثال:

echo Hello CyberPath
echo %USERPROFILE%

النتيجة: طباعة النص أو قيمة متغير البيئة.

5) exit

الصيغة:

exit

الوظيفة: إغلاق نافذة CMD.

6) title

الصيغة:

title [نص]

مثال:

title Security Audit Session

يفيد في تمييز نافذة التحقيق عند فتح عدة نوافذ.

الاستخدامات الأمنية

  • توثيق كل خطوة تحقيق عبر echo وtitle.
  • التحقق من الصلاحيات قبل تنفيذ أوامر حساسة.
  • استخدام /? لتفادي أخطاء الأوامر الخطرة.

الأخطاء الشائعة

  • نسيان أن الأمر يحتاج صلاحيات مسؤول.
  • كتابة المسار بـ / بدلًا من \ في أوامر Windows.
  • نسخ أوامر من الإنترنت دون فهمها — خطر أمني حقيقي.
تحذير: لا تشغّل أوامر من مصادر غير موثوقة على جهازك الشخصي. استخدم دائمًا جهازًا افتراضيًا (VM) للتدريب.

تمارين عملية

  1. افتح CMD كمسؤول وتحقق من whoami.
  2. اعرض توثيق الأمر copy.
  3. اطبع قيمة %USERNAME% و %COMPUTERNAME%.

تحديات تطبيقية

  • غيّر عنوان النافذة إلى "Baseline Check".
  • اكتب أمرًا يطبع تاريخ اليوم باستخدام echo %DATE% %TIME%.
  • ابحث باستخدام /? عن خيار يعرض مساعدة الأمر net.
