خريطة المجالات الدراسية

تغطي الخطة الدراسية للدبلوم المجالات التالية، مع توضيح أعداد الأسئلة المتاحة في النماذج والاختبار التكاملي لكل مجال:

المجال / المقرر المواضيع الأساسية للتركيز عدد الأسئلة المتاحة مصدر الأسئلة نوع الأسئلة
تجميع الحاسب وصيانته المكونات المادية، التركيب، الصيانة الوقائية والعلاجية، التشخيص، RAID، BIOS/UEFI 15 سؤالاً الاختبار التكاملي نظري + عملي
شبكات الحاسب أنواع الشبكات، نموذج OSI، البروتوكولات (TCP/IP, DNS, DHCP)، العناوين، الأجهزة، الكابلات، الأوامر 20 + 30 سؤالاً الاختبار التكاملي + النموذج الثالث نظري
تحليل وتصميم النظم دورة حياة تطوير النظم (SDLC)، DFD، ERD، دراسات الجدوى، نماذج التطوير (Waterfall, Agile)، الاختبار، الصيانة 15 سؤالاً الاختبار التكاملي نظري
تقنيات الإنترنت وتطوير المواقع HTML, CSS, JavaScript, نماذج الويب (GET/POST)، الخوادم (PHP/Node.js)، التصميم المتجاوب، Bootstrap، FTP 15 + 25 مهمة الاختبار التكاملي + النموذج الرابع عملي
أمن الشبكات وأخلاقيات التقنية CIA Triad، التشفير (Symmetric/Asymmetric)، Firewall، VPN، SSH، الهندسة الاجتماعية، البرمجيات الخبيثة، أخلاقيات المهنة 15 سؤالاً الاختبار التكاملي نظري
الدعم الفني ونظم التشغيل Windows Server، Active Directory، Device Manager، Task Manager، Ticketing Systems، مهارات التواصل، حل المشكلات 20 سؤالاً الاختبار التكاملي نظري + عملي
البرمجة وقواعد البيانات أساسيات البرمجة (C++/JavaScript)، SQL (SELECT, INSERT, UPDATE, DELETE, JOIN)، تصميم قواعد البيانات 35 سؤالاً النموذج الثاني عملي
مهارات الحاسب التطبيقية Microsoft Word (متقدم)، Excel (دوال البحث، الجداول المحورية)، PowerPoint 25 مهمة عملية النموذج الرابع عملي
المهارات العامة الإنجليزية التقنية، أخلاقيات المهنة، مهارات التواصل مدمجة جميع النماذج اختياري
ملاحظة: الأعداد المذكورة تمثل الأسئلة المتاحة فعلياً في النماذج والاختبار التكاملي. استخدم هذه الخريطة لتوزيع وقت المراجعة بشكل متوازن.
