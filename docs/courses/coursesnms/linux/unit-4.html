الوحدة 4: أوامر إدارة المستخدم والمجموعة

تعلم كيفية إضافة، تعديل، وحذف المستخدمين والمجموعات في نظام لينكس

الرئيسية > الوحدة 4

نظرة عامة

تُعد إدارة المستخدمين والمجموعات من المهام الأساسية لأي مسؤول نظام. في لينكس، يتم التعامل مع المستخدمين والمجموعات من خلال سطر الأوامر، مما يمنحك تحكمًا كاملاً في صلاحيات الوصول إلى الملفات والخدمات.

قائمة الأوامر

الأمر الوصف
useradd لإنشاء مستخدم جديد. مثال: sudo useradd newuser.
userdel لحذف مستخدم. مثال: sudo userdel olduser.
usermod لتعديل بيانات مستخدم موجود. مثال: sudo usermod -aG groupname username.
groupadd لإنشاء مجموعة جديدة. مثال: sudo groupadd newgroup.
groupdel لحذف مجموعة. مثال: sudo groupdel oldgroup.
id يعرض معلومات الهوية (UID و GID) لمستخدم معين.
last يعرض قائمة بآخر المستخدمين الذين قاموا بتسجيل الدخول.

أمثلة عملية

لإنشاء مستخدم جديد باسم testuser و إعطائه كلمة مرور:

sudo useradd testuser
sudo passwd testuser

لإضافة المستخدم testuser إلى مجموعة sudo:

sudo usermod -aG sudo testuser

للتحقق من المجموعات التي ينتمي إليها المستخدم testuser:

id testuser
تنبيه: تتطلب معظم أوامر إدارة المستخدمين والمجموعات صلاحيات الجذر (root)، لذا يجب استخدامها بحذر ومع الأمر sudo.
