ملخصات سريعة حسب الوحدات

الوحدة 1: الأوامر الأساسية

أهم الأوامر 
# التنقل والاستكشاف
ls          # عرض المحتويات
cd          # تغيير المجلد
pwd         # عرض المسار الحالي

# إدارة الملفات
touch       # إنشاء ملف
mkdir       # إنشاء مجلد
cp          # نسخ
mv          # نقل/إعادة تسمية
rm          # حذف

# عرض المحتوى
cat         # عرض محتوى الملف
less        # عرض صفحة بصفحة
head        # عرض البداية
tail        # عرض النهاية

الوحدة 2: أوامر الشبكة

أهم الأوامر 
# معلومات الشبكة
ifconfig    # عرض إعدادات الشبكة (قديم)
ip addr     # عرض إعدادات الشبكة (حديث)
ip route    # عرض جدول التوجيه

# اختبار الاتصال
ping        # اختبار الاتصال
traceroute  # تتبع المسار
netstat     # إحصاءات الشبكة
ss          # معلومات المقابس

# استعلامات DNS
nslookup    # استعلام DNS
dig         # استعلام DNS مفصل
whois       # معلومات النطاق

الوحدة 3: إدارة الصلاحيات

أهم الأوامر 
# إدارة الأذونات
chmod       # تغيير أذونات الملف
chown       # تغيير مالك الملف
chgrp       # تغيير مجموعة الملف

# الصلاحيات الخاصة
umask       # تعيين أذونات افتراضية
setfacl     # إدارة قوائم التحكم بالوصول

# إدارة sudo
visudo      # تحرير إعدادات sudo
sudo        # تنفيذ أوامر بصلاحيات root

اختبر معرفتك

اختبر فهمك لأوامر لينكس التي تعلمتها في هذا المقرر:

1. ما هو الأمر المستخدم لعرض محتويات مجلد مع التفاصيل الكاملة including الأذونات والملاك؟

2. كيف يمكنك تغيير أذونات ملف ليكون قابل للقراءة والكتابة والتنفيذ by المالك، readable by المجموعة، ولا شيء للآخرين؟

3. ما هو الفرق بين apt update و apt upgrade؟
