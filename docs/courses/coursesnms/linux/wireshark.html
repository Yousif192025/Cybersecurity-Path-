مشاريع Wireshark للمبتدئين

تعلم تحليل حركة الشبكة والتحقيق في الأمن السيبراني باستخدام Wireshark

نظرة عامة

هذا المستودع يحتوي على خمسة مشاريع للمبتدئين تركز على استخدام Wireshark للتحقيق الجنائي الرقمي والأمني. كل مشروع يوفر تجربة عملية مع التقنيات الأساسية لالتقاط وتحليل حركة الشبكة لتحديد المشكلات الأمنية المحتملة وتحسين أداء الشبكة.

ملاحظة: هذه المشاريع مصممة للمبتدئين في مجال تحليل الشبكات والأمن السيبراني.

المشاريع المتاحة

1. تحليل حركة HTTP باستخدام Wireshark

تعلم كيفية التقاط وتحليل حركة HTTP باستخدام Wireshark. يغطي هذا المشروع إعداد عمليات الالتقاط، تصفية حركة HTTP، تحليل طلبات HTTP واستجاباتها، واستخراج بيانات الحمولة.

الموضوعات الرئيسية: حركة HTTP تحليل الحزم التصفية استخراج البيانات

الأدوات: Wireshark، متصفح الويب

عرض المشروع

2. الكشف والتحقيق في حركة البرمجيات الخبيثة

استخدم Wireshark للكشف عن والتحقيق في حركة البرمجيات الخبيثة. يتضمن هذا المشروع تحديد الأنماط المشبوهة، تحليل الحزم الخبيثة، متابعة تدفقات اتصال البرمجيات الخبيثة، وتوثيق النتائج.

الموضوعات الرئيسية: كشف البرمجيات الخبيثة تحليل الحركة مؤشرات الاختراق التقارير

الأدوات: Wireshark، ملفات PCAP نموذجية

عرض المشروع

3. Wireshark لاكتشاف التسلل إلى الشبكة

تعلم استخدام Wireshark لاكتشاف التسلل إلى الشبكة. يركز هذا المشروع على تحديد مؤشرات الاختراق، تحليل الحزم المشبوهة، متابعة تدفقات اتصال التسلل، وتوثيق النتائج.

الموضوعات الرئيسية: اكتشاف التسلل تحليل الحركة مؤشرات الاختراق التقارير

الأدوات: Wireshark، ملفات PCAP نموذجية

عرض المشروع

4. فك تشفير وتحليل حركة SSL/TLS

أتقن عملية فك تشفير وتحليل حركة SSL/TLS باستخدام Wireshark. يتضمن هذا المشروع تكوين إعدادات فك التشفير، تصفية حركة SSL/TLS، تحليل الحزم المفكوكة، ومتابعة تدفقات الاتصال الآمنة.

الموضوعات الرئيسية: فك تشفير SSL/TLS تحليل الحركة الآمنة التصفية تدفقات الاتصال

الأدوات: Wireshark، ملفات المفاتيح الخاصة، ملفات PCAP نموذجية

عرض المشروع

5. التقاط وتحليل حركة VoIP

التقط وحلل حركة VoIP باستخدام Wireshark. يغطي هذا المشروع التقاط مكالمات VoIP، تصفية حركة SIP وRTP، تحليل حزم SIP، فحص تدفقات RTP، وتشغيل صوت مكالمات VoIP.

الموضوعات الرئيسية: حركة VoIP SIP RTP تحليل المكالمات التشغيل

الأدوات: Wireshark، شبكة VoIP أو ملفات PCAP نموذجية

نصائح للمبتدئين

تنبيه: تأكد من استخدام Wireshark في بيئة آمنة ومرخصة فقط. تحليل حركة الشبكة على شبكات غير مصرح بها قد يكون غير قانوني.

بيئات التدريب الموصى بها:

  • VirtualBox مع Kali Linux أو توزيعة مشابهة
  • منصات التدريب الآمنة مثل TryHackMe و HackTheBox
  • معامل الشبكات المعزولة

مهارات مطلوبة مسبقاً:

  • مفاهيم أساسية في الشبكات (TCP/IP، المنافذ، البروتوكولات)
  • معرفة أساسية باستخدام سطر الأوامر
  • فهم أساسي لمفاهيم الأمن السيبراني
