الوحدة 7: أوامر إدارة الحزم

تثبيت، تحديث، وإزالة البرامج في نظام لينكس

الرئيسية > الوحدة 7

نظرة عامة

في نظام لينكس، تتم إدارة البرامج من خلال "مديري الحزم". يختلف مدير الحزم المستخدم باختلاف توزيعة لينكس. في هذه الوحدة، سنغطي أشهر مديري الحزم في التوزيعات الشائعة: Debian/Ubuntu (باستخدام apt) و Red Hat/CentOS (باستخدام yum).

إدارة الحزم في Debian/Ubuntu

تستخدم توزيعات مثل دبيان وأوبونتو مدير الحزم APT (Advanced Package Tool).

الأمر الوصف
sudo apt update يحدّث قائمة الحزم المتاحة من المستودعات.
sudo apt upgrade يحدّث جميع الحزم المثبتة إلى أحدث إصداراتها.
sudo apt install لتثبيت حزمة جديدة. مثال: sudo apt install htop.
sudo apt remove لإزالة حزمة.
dpkg -i لتثبيت حزمة .deb تم تنزيلها يدويًا.

إدارة الحزم في Red Hat/CentOS/Fedora

تستخدم هذه التوزيعات مدير الحزم YUM (Yellowdog Updater, Modified) أو DNF الأحدث.

الأمر الوصف
sudo yum check-update يتحقق من وجود تحديثات للحزم.
sudo yum update يحدّث جميع الحزم.
sudo yum install لتثبيت حزمة جديدة.
sudo yum remove لإزالة حزمة.
